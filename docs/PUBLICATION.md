# LinkQR — Publication checklist

## Version
- App version: **1.0.0**
- versionCode: **1**
- Minimum Android: **API 24**
- Target Android: **API 37**

## App identity
- Launcher logo: @drawable/ic_launcher
- App name: **LinkQR**
- Default QR colors: **black QR / white background**

## QR customization
The generator now exposes RGB controls for both the QR foreground and background:
- Red: 0–255
- Green: 0–255
- Blue: 0–255
- Live HEX preview
- Readability validation remains enforced before generation

The default values are #000000 for the QR and #FFFFFF for the background.

## Release build
- CI validates the debug APK.
- CI validates the release APK.
- CI runs unit tests.
- CI publishes JUnit/HTML test reports.

The release APK generated by CI is intentionally **unsigned**. The final Play Store upload must be signed with the production upload key in a secure environment. No keystore or signing credentials belong in this repository.

## Google Play Console
1. Create/configure the application in Play Console.
2. Configure the production application ID `com.linkqr`.
3. Complete the store listing, screenshots and app description.
4. Complete the Data safety form.
5. Provide the required privacy-policy URL for the production listing.
6. Configure AdMob production identifiers and consent configuration.
7. Configure the `linkqr_pro` product.
8. Configure the developer/payment profile for Play payouts.
9. Sign the release bundle/APK with the production upload key.
10. Upload the signed production artifact and complete Play's pre-launch checks.

## Important
CI proves that the release build compiles; it does not constitute a Play Store publication. Signing, Play Console configuration, production ad IDs, store metadata and policy declarations remain deployment tasks.
